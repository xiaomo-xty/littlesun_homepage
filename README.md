# littlesun.space

个人叙事型工程师主页。网站以个人经历、关注的问题和做事方式为主体，项目、文章和技术栈作为证据。

## 当前状态

- 设计基线：Penpot V6 概念原型已确认
- 实现栈：Astro + Bun
- 目标域名：`littlesun.space`
- 博客入口：`https://blog.littlesun.space`
- 当前阶段：工程初始化

## 内容原则

- 不虚构姓名、联系方式、履历、项目进度或性能指标。
- 未提供的姓名、照片、简历、GitHub 与邮箱保留明确占位符。
- SceneScope 是主要代表项目之一，不是个人主页品牌。
- 商业 C++ 经历只描述可公开范围，不包含公司代码、样本或协议细节。
- 文章只展示真实发布内容；开发期保留草稿槽位，但必须标记为占位。

## 开发命令

项目骨架完成后，本节将提供 `bun install`、`bun run dev`、`bun run check` 与 `bun run build` 命令。
