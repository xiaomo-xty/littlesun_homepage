# v0.14 水母牵引节奏与柔性运动

## 目标

- 让首次进入中的“水母牵引 + 海流托举”真正可被看见，而不是正文快速弹出后只留下结果。
- 保留背景水母的生物推进感，同时去掉钟形体过度拉伸、推进时猛转和触手高频甩动。
- 继续保持背景逻辑与显示帧分离，所有水母位置、速度、朝向和触手链仍由固定 `60 Hz` 步进更新。

## 开场时间线

正常路径使用三个连续阶段：

1. 水母入镜并在视口中落稳，名义时长从 `720 ms` 调整为 `820 ms`。
2. 触手建立张力并完成一次回弹，最长名义时长从约 `444 ms` 调整为约 `562 ms`。
3. 水母、海流、导航、Hero 文本和个人视觉舞台同步上升。最长名义时长从约 `1.68 s` 调整为约 `3.01 s`。

整个正常编舞的配置时长约为 `4.87 s`，比 v0.12 的约 `3.32 s` 增加约 `1.55 s`。新增关键帧把前 `18%-22%` 留给蓄力，只移动少量距离；中段完成主要牵引，末段再轻微越位并回正。故障保护路径继续使用原快速时长，不让渲染失败变成长等待。

根节点新增 `data-choreography-phase` 与 `data-choreography-duration-ms`，用于区分 `arrival`、`tension`、`tow` 和 `complete`，也便于后续回归开场状态机。

## 背景水母

水母姿态由新的纯函数 `sampleJellyPose` 统一采样：

- 钟形体横向最大收缩由 `23%` 降为 `13%`。
- 纵向最大拉伸由 `14%` 降为 `5.5%`，推进峰值会抵消一部分纵向拉伸。
- 推进倍率由 `3.05` 降为 `1.9`，阻尼由 `1.28` 调整为 `1.08`，形成较柔和的加速与更长的惯性滑行。
- 推进阶段不再额外提高转向增益；方向响应保持缓慢，双频游移的总幅度限制在约 `0.18 rad`。
- 移除显示层独立的大幅横摆，钟形体只保留低幅呼吸。
- 触手根部、链长和末端波幅全部跟随同一姿态采样；波幅根据速度与推进变化，限制在 `0.006-0.024`。

显示层只插值位置、朝向和固定步进后的触手点，不改写逻辑状态。因此 `30 / 60 / 120 fps` 下仍共享相同的逻辑 tick，渲染帧率只影响显示插值。
