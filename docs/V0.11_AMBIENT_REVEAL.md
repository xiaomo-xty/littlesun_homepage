# v0.11 背景揭示与生物色差

## 目标

- 水母每次收缩后沿朝向获得短促推进，形成可见但不过量的反冲滑行。
- 水母、珊瑚与海洋静物保留现有蓝青色系，只增加低幅度个体色差。
- 生物发光必须体现亮度变化，而不是持续不变的透明外轮廓。
- 页面进入顺序固定为：主题加载器、完整背景、正文上浮、背景退后。
- 背景最终状态不得影响标题、正文、导航与交互控件的辨识。

## 状态机

根节点 `data-experience` 依次经过：

1. `loading`：加载门覆盖页面，正文带 `inert` 且不可见。
2. `ambient`：加载门淡出，背景提高亮度与饱和度，后处理降为 0，正文仍隐藏。
3. `entering`：移除正文 `inert`，正文从下方缓入，背景和后处理同步回到阅读态。
4. `ready`：保持稳定的阅读层级。

背景通过 `homepage:ambient-ready` 通知加载门；WebGPU、WebGL2、static 与渲染失败回退都使用同一信号。加载门最短显示约 `820 ms`，背景独立展示约 `1.32 s`，确保后处理完全退场后仍有可感知的完整画面。`4.8 s` 故障保护使用快速放行，避免用户被永久锁在加载页。

## 动效边界

- 水母推进使用 `3.05` 的脉冲倍率，但继续受 `0.24` 独立速度上限保护。
- 辉光采样静息值约为 `0.035`，推进阶段接近 `1`，舒张阶段只保留弱余辉。
- 水母使用核心与外层两个 additive halo；亮度、透明度和尺度同步随脉冲变化。
- 个体色差的色相偏移限制在约 `±0.016`，明度偏移限制在约 `±0.022`。
- 珊瑚仍不发光；海花、海玻璃和近景像素保留低频选择性发光。

## 可读性

- 最终阅读态继续使用全局低饱和后处理。
- Hero 和区块标题增加无边框、带渐隐边缘的局部阅读柔化层。
- 文章行使用顺向半透明底色，不引入新的卡片容器。
- `prefers-reduced-transparency` 下关闭局部模糊并提高实体底色不透明度。
- `prefers-reduced-motion` 下跳过大位移，并由 static 背景直接完成快速揭示。
