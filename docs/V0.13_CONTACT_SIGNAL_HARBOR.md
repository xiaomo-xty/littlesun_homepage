# v0.13 联系区信号港湾

## 问题

旧联系区使用整块高饱和蓝色作为背景。它与上方太空海洋突然断开，抹平了背景纵深、编辑式排版与像素细节，也让博客按钮、联系链接和页脚像临时落在一张广告底板上。

## 设计调整

- 移除整区蓝色填充，恢复带 `0.9` 页面底色的阅读层，让太空海洋只以低对比轮廓透出。
- 使用短蓝色顶线、三条弧形海流、同心信号浮标和少量像素点表达“开放通信”，蓝色不再承担整块背景。
- 标题与联系状态使用非对称两栏，形成从个人叙事到可执行入口的收束。
- 下方使用一条带分隔线的联系轨道，不创建四张独立卡片。
- 博客作为主要阅读入口占据左侧，GitHub、简历和邮箱在右侧分层排列；移动端统一为单列轨道。

## 交互与内容边界

- 博客和 GitHub 是真实链接，hover 时只局部点亮、轻抬图标并推动箭头。
- 简历和邮箱继续显示 `PENDING` 与真实占位说明，不伪造文件或地址，也不提供虚假点击。
- 区块进入视口时，标题、状态与四条轨道继续使用已有可重复分层动画。
- `prefers-reduced-motion` 下禁用信号脉冲以及入口、图标和箭头的位移。

## 响应式

- 桌面使用 `1.12 / 0.88` 非对称轨道，联系区高度约 `791 px`。
- `390 x 844` 使用单列轨道，宽约 `335 px`，联系区高度约 `933 px`，域名与备案号完整显示。
- 深浅主题均保留结构线与文字对比，文档横向溢出为 0。
