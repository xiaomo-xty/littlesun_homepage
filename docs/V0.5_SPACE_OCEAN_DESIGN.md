# v0.5 太空海洋背景设计

日期：2026-08-18

分支：`feature/v0.5-space-ocean`

## 设计判断

这是面向招聘者与技术同行的个人工程师作品集改造。人物与职业叙事仍是主体，背景只负责提供生命感、图形技术证据和可发现的互动。

- `DESIGN_VARIANCE 7`
- `MOTION_INTENSITY 7`
- `VISUAL_DENSITY 4`
- 视觉语言：编辑式个人主页 + 低对比太空海洋生态
- 渲染策略：WebGPU 优先，WebGL2 与静态 CSS 降级

## 检索结论

### 1. 群游行为

[WebGPU Samples - Compute Boids](https://webgpu.github.io/webgpu-samples/?sample=computeBoids) 使用分离、对齐、聚合三条局部规则，并通过双缓冲更新粒子状态。这套规则适合小型群游生物，但当前主页不需要把全部行为迁移到计算着色器。

本轮采用同一行为模型，在 CPU 上控制少量生物。这样能保持 WebGL2 降级一致，并把计算预算留给渲染。后续只有实测数量或性能需要时再迁移到 WebGPU compute。

### 2. 曲线形态

[Three.js CatmullRomCurve3](https://threejs.org/docs/pages/CatmullRomCurve3.html) 提供由控制点生成连续曲线的成熟实现。它适合尾迹、触须与流线，比关节式蜘蛛腿更符合太空海洋的柔软形态。

本轮使用动态控制点和 Catmull-Rom 采样绘制：

- 主生物的三条尾带
- 群游生物的短尾迹
- 横跨视口的慢速流场线

控制点通过简化弹簧链跟随头部，不每帧创建新的几何体和材质。

### 3. 透明与磨砂

[MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter) 说明磨砂需要透明或半透明表面才能看见效果。全屏强模糊会增加合成成本，也容易让页面发灰。

本轮只采用轻量方案：

- 降低 Canvas 总体透明度和对比度
- 用半透明页面色做雾化隔离
- 在已有内容表面使用低半径 `backdrop-filter`
- 为 `prefers-reduced-transparency` 提供纯色回退

## 形态与行为

### 主生物：星鳐

- 轮廓由二次贝塞尔曲线组成，像鳐鱼、叶片和飞船之间的抽象形态
- 翼面缓慢起伏，身体朝速度方向旋转
- 三条尾带使用弹簧链和 Catmull-Rom 曲线
- 游走目标、页面安全区、边界、附近实体共同影响路径
- 鼠标只产生斥力，不吸引生物
- 与实体接触时推动实体，并触发现有破碎规则

### 群游生物

- 数量控制在桌面 18、平衡模式 10
- 使用分离、对齐、聚合和流场四种权重
- 遇到鼠标时快速散开，随后重新聚合
- 采用小型弧形头部和短尾，不做卡通鱼眼或写实水母

### 漂浮实体

- 保留碰撞、旋转、破碎和边界响应
- 可见轮廓改为胶囊、圆盘与弯叶，不再使用生硬方块
- 完全删除椭圆接触阴影
- 颜色通过透明填充、细描边和碰撞时短暂增亮表达层级

### 微粒与流线

- 像素粒子仍是特效，不参与碰撞
- 流线表示太空海洋的缓慢水流，不承担信息
- 空闲时仍有相位、位置、大小和亮度变化

## 视觉预算

- 浅色 Canvas 目标透明度：约 0.48
- 深色 Canvas 目标透明度：约 0.56
- 实体填充透明度：浅色 0.12-0.2，深色 0.08-0.16
- 主生物描边保持可辨，正文区域由安全区与雾化层双重保护
- 不使用发光球、霓虹外发光、写实投影或全屏重模糊

## 性能与降级

- WebGPU 是默认渲染路径
- `?ambient=webgl2` 强制 WebGL2 平衡模式
- `?ambient=static`、省流量或 reduced-motion 使用静态太空海洋图形
- 页面不可见时停止动画循环
- 所有事件、观察器、几何体、材质和渲染器必须清理
- 移动端降低 DPR、生物数量、实体数量和曲线采样数

## 验收标准

- 页面中不存在 `arthropod`、蜘蛛腿、脚点或接触阴影
- `data-creature="space-ray"`
- 鼠标对实体和生物保持斥力
- 群游能散开并重新聚合
- 实体仍能碰撞、破碎，复杂形态转为更小集合
- 浅色与深色中都能看到生物和实体，但背景不压过正文
- WebGPU、WebGL2、静态三条路径都可用
- reduced-motion 与 reduced-transparency 有明确降级
