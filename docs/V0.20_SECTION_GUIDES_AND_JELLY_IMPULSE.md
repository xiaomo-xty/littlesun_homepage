# v0.20 区块引导与水母蓄力冲击

## 目标

- 让 Hero 和其他主要区块一样拥有可重复触发的进场与退场。
- 在每个主要区块底部提供一致、可点击的下一页引导。
- 让开场水母先完成可辨认的蓄力，再用一次短促冲击带动页面进入。

## Hero 进退场

Hero 继续保留左右分栏，不改变内容与信息层级。动效拆成三个独立层：

1. 文案从左下方轻微进入，伴随小幅缩放。
2. 个人视觉舞台从右下方进入，带 1.6 度以内的轻旋转。
3. 区块引导最后显现。

三个层都由现有 `IntersectionObserver` 写入 `visible` 和 `hidden` 状态。离开视口后会退场，重新滚回时再次进入，不采用只播放一次的开场动画。

## 区块引导

新增一个轻量 `SectionGuide` 组件，映射关系如下：

| 当前区块 | 目标区块 |
| --- | --- |
| Hero | 关于我 |
| 关于我 | 代表项目 |
| 代表项目 | 代表文章 |
| 代表文章 | 生活侧面 |
| 生活侧面 | 联系 |
| 联系 | 返回顶部 |

引导只显示双箭头和一条弱海流弧线，不增加说明文字。`aria-label` 与 `title` 提供可访问名称，焦点状态沿用全站规则。桌面 Hero 的引导固定在首屏底部；移动端改为正常文档流，避免覆盖视觉舞台。

箭头的低频漂移用于提示可继续阅读，悬浮时增强强调色与弧线。`prefers-reduced-motion` 下动画会被全局低动态规则关闭。

## 水母编舞

正常路径调整为：

1. `arrival`：水母从视口下方进入。
2. `tension`：触手建立张力，海流前沿出现。
3. `charge`：页面保持在视口外，水母略微下沉，钟形体压缩，触手收束，光环集中。
4. `impulse`：钟形体快速回弹，水母、海流与页面同步向上移动第一段距离。
5. `tow`：共享连续贝塞尔速度曲线完成剩余牵引。
6. `release`：海流前沿淡出，页面恢复交互。

正常编舞中，蓄力为 `640 ms`，冲击为 `420 ms`，后续牵引为 `1850 ms`。故障保护快速路径保留同样的阶段结构，但使用 `190 ms`、`170 ms` 和 `620 ms`。所有新增关键帧只动画 `transform` 与 `opacity`。

## 范围与降级

- 不修改导航、区块 ID、正文、项目数据或外部链接。
- 不修改背景仿真、固定 `60 Hz` 逻辑步进或 WebGPU 渲染路径。
- WebGPU、WebGL2 与 static 共用同一套页面编舞。
- `prefers-reduced-motion` 继续使用 `220 ms` 淡入，不播放蓄力和牵引。
- 深链接裁切、加载阶段 `inert`、滚动锁定与临时样式清理保持不变。
- 未修改 `D:\project\blog`。
