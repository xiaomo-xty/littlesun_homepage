# v0.4 界面减法与背景生态设计

日期：2026-08-18

分支：`feature/v0.4-emergent-ambient`

## 目标

本轮是对 v0.3 的针对性演进，不改变个人主页的信息架构、锚点、主题切换和卡牌交互。

- 删除打断阅读节奏的技术横条。
- 取消项目区重复的 Problem / Process / Evidence 展示。
- 调整浅色主题为更干净的瓷白底色，保持蓝色品牌线索。
- 将背景分成像素特效、可碰撞实体和程序化多足生物三层。
- 用少量确定规则产生碰撞、弹开、踢击和破碎行为。

设计参数保持：`DESIGN_VARIANCE 7 / MOTION_INTENSITY 8 / VISUAL_DENSITY 5`。

## 界面减法

### 技术横条

整段删除，不替换为新的装饰条。技术方向已经由首屏、成长轴和项目卡证明，重复罗列会让个人叙事退化为关键词墙。

### 项目证据

Problem / Process / Evidence 只保留在卡牌详情层。左侧侧板改为牌组索引，只承担导航和当前卡定位，不再复述卡面内容。

移动端继续使用卡后的证据摘要入口，详情正文仍来自同一个卡牌详情层。

## 浅色主题

- 页面基底改为中性偏暖的瓷白，不使用大面积冷灰蓝。
- 普通内容表面使用接近纯白的高明度色。
- 蓝色只用于交互、边缘和少量层级强调。
- 背景实体在浅色下使用更深的实体描边、可辨识填充和低成本接触阴影。
- 像素粒子继续保持更浅、更小，避免与实体混淆。

## 背景对象分层

### 像素特效

- 34 个移动端粒子，72 个桌面粒子。
- 不参与实体碰撞。
- 响应点击和项目抽牌脉冲，但不承担空间叙事。

### 几何实体

- 移动端最多 8-10 个，桌面最多 14 个。
- 初始类型包括长方形、圆形和三角形。
- 使用二维位置、速度、角速度、半径、质量和复杂度级别描述。
- 两两使用包围圆做窄相碰撞，数量上限下每帧最多 91 次配对检查。
- 碰撞会改变速度、角速度、尺度脉冲和边缘亮度。

### 多足生物

- 采用俯视的程序化节肢体轮廓：身体、头部、八条两段式腿。
- 腿端根据速度和转向错相摆动，静止时仍保留轻微呼吸。
- 行为权重由游走目标、边界、安全区、附近实体和鼠标斥力共同组成。
- 鼠标只产生斥力。指针移动越快，生物和实体获得的弹开冲量越强。
- 生物靠近实体时可以踢开实体；满足碰撞强度和冷却条件时触发破碎。

## 破碎规则

- 圆形破碎为三个三角形。
- 长方形破碎为两个更小长方形和两个三角形。
- 三角形破碎为两个更小三角形。
- 最小复杂度碎片不再分裂，只参与碰撞、旋转和边界反弹。
- 达到实体数量上限时不继续生成碎片，只施加弹开和属性变化。

## 性能与降级

- 不新增第三方物理依赖，不在动画帧更新 React 状态。
- 使用现有 Three.js WebGPU 主路径和 WebGL2 fallback。
- 页面隐藏时暂停，DPR 和粒子数量继续分级。
- `prefers-reduced-motion`、省流量或 `?ambient=static` 使用静态背景。
- 静态背景也区分实体和像素特效，并保证浅色主题可见。
- 暴露 `data-creature`、`data-pointer-force`、`data-entity-count` 和 `data-fracture-count` 供浏览器验收。

## 验收标准

- 技术横条从桌面和移动端消失，章节之间没有突兀反色块。
- 项目区 Problem / Process / Evidence 只出现一次。
- 浅色主题实体轮廓与填充清晰可见，正文对比度不降低。
- 鼠标接近生物和实体时，两者都远离鼠标。
- 实体之间会反弹并改变旋转或视觉状态。
- 多足生物能游走、避让安全区、踢开实体并触发至少一种破碎。
- WebGPU、WebGL2 和静态路径均为 `ready`，无控制台错误和页面溢出。
