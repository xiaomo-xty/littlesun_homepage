# 内容边界

- 职业主轴是高性能图形、游戏引擎工具与跨平台系统。
- C++ 是当前求职锚点，Rust 是主要成长语言。
- 关注 wgpu、WebGPU、Wasm、图形学、资源管线、编辑器与性能工具。
