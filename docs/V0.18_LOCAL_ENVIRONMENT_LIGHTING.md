# v0.18 局部环境照明

## 目标

发光物体不只提高自身亮度，还应让附近水体结构、粒子和静物随距离变亮。效果需要跟随生物位置与脉冲变化，同时保持正文阅读优先。

## 设计边界

- 保持冷蓝太空海洋配色，不增加新的高饱和强调色。
- 不增加发光物体数量，只改变现有发光体对环境的影响。
- 光场边缘必须柔和，不能形成固定圆斑或装饰性光球。
- 浅色主题只保留弱蓝色高光，暗色主题允许更明确的亮度峰谷。
- 正文进入后沿用现有画布压低与阅读保护，不让背景盖过文字。

## 光照模型

每个光源包含二维位置、影响半径和强度。采样点到光源的距离先归一化，再通过平滑曲线衰减：

```text
influence = intensity * smoothstep(1 - distance / radius)
```

半径外影响为零。多个光源线性叠加后由调用方设置上限，避免密集区域过曝。

当前光源来自：

- 水母：亮度跟随收缩、推进和余辉采样。
- 发光静物：亮度跟随低频 shimmer 与出生可见度。
- 海豚：提供弱而宽的移动环境光，不作为主发光体。
- 近景发光粒子：提供小半径、低强度的局部闪烁。

## 渲染结构

局部光数据在每个显示帧根据固定步进的前后状态插值生成。物理与生物行为仍按固定 `60 Hz` 更新，帧率只影响显示插值。

视觉光场使用正交相机中的平面网格和透明径向纹理。普通透明混合负责形成水体亮区，物体自身 halo 继续使用加法混合。这样可以避开 WebGPU 路径中 Sprite 光场未稳定进入输出的问题。

同一光源列表用于三类环境响应：

- 静物材质颜色、填充透明度和轮廓亮度。
- 像素粒子的颜色与近景小光晕。
- 海流曲线的逐顶点颜色。

static 降级不运行动态光源，只使用三个固定的弱径向渐变保持视觉语义。

## 性能与降级

- 桌面完整质量当前约 20 个光源，移动和平衡质量约 13 个光源。
- 受光采样只覆盖少量静物、粒子和海流采样点，未引入阴影贴图、后处理 bloom 或全屏多次渲染。
- `prefers-reduced-motion`、省流量和主动 `?ambient=static` 继续使用静态降级。
- `?ambient=webgl2` 使用与 WebGPU 相同的场景数据和光场材质。

## 验收标准

- 水母移动和脉冲时，周边亮区与它保持一致。
- 光源附近的海流、像素和静物比远处同类元素更亮。
- 光照在半径外消失，多光源重叠不导致整片背景过曝。
- 暗色完整背景阶段效果清楚，正文阶段仍然克制。
- 浅色主题实体可见，局部高光不降低文字对比。
- WebGPU、WebGL2、static、桌面和移动端均有有效输出。
