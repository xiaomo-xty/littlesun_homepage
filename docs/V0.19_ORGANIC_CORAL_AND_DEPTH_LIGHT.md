# v0.19 有机珊瑚与环境明暗

## 目标

- 让背景珊瑚在低透明度和小尺寸下仍能被识别为海洋静物。
- 避免所有珊瑚共享同一种硬折线树枝形态。
- 删除全页移动扫光，让明暗关系回到深度、局部光源和生物发光。

## 珊瑚语言

动态背景保留三种轮廓，每种承担不同的识别线索：

1. 海扇：宽扇形外轮廓，内部使用放射状主脉和横向连接脉。
2. 鹿角珊瑚：不对称分叉和圆润枝端，避免读成规则树枝或手掌。
3. 管状珊瑚簇：高低不同的软管轮廓，顶部开口提供小尺寸识别线索。

三种形态复用现有实体运动、碰撞、回正和固定时间步，不引入额外仿真分支。完整质量展示三种，移动端与 WebGL2 的平衡质量展示两种。

static 降级层使用带分支叶脉的海扇轮廓，不再使用单块树枝形 `clip-path`。

## 光影边界

删除：

- 全页双宽幅移动光带。
- 对应的暗色、移动端、低动态和低透明度规则。
- 两组背景扫光关键帧。

保留：

- 水母、海豚、发光静物和近景像素产生的局部环境光。
- 远近像素的尺寸与亮度差异。
- 海流曲线经过局部光源时的受光响应。
- Hero 视觉舞台和当前项目卡内部的局部材质反馈。

背景明暗因此来自空间关系和物体行为，不再来自覆盖整页的装饰性光带。

## 可见性

- 珊瑚在浅色主题使用更明确的强调色描边和叶脉。
- 暗色主题保持较低填充透明度，以描边和内部纹理承担识别。
- 正文阶段仍由现有后处理层降低背景存在感，不提高整个画布亮度。

## 验证范围

- WebGPU：桌面完整质量、浅色与暗色、移动端平衡质量。
- WebGL2：平衡质量和珊瑚轮廓。
- static：海扇降级轮廓。
- 扫光节点与源码残留搜索。
- 现有 60 Hz 仿真、碰撞、路径和局部光测试。
