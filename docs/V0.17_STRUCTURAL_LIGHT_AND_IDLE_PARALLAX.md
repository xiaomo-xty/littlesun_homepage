# v0.17 结构光与空闲视差

## 定义

这一版不是传统彩虹镭射。视觉语言定义为冷色结构光、薄膜反射和分层视差：

- 色相只使用现有冷蓝、冷灰蓝和少量森林绿关系，不增加彩虹漂移。
- 光以宽幅斜向带出现，不使用装饰性光球或大面积泛光。
- 视差表达前后层级和可交互性，不模拟持续摇晃的水面。
- 文字始终位于稳定阅读层，结构光只进入背景空域、Hero 视觉视口和当前项目卡材质层。

## 动效职责

### 背景

- 两条宽幅结构光分别以 `16 s` 和 `18 s` 周期错峰扫过。
- 单次明显出现只占周期约四分之一，其余时间保持安静。
- 完整背景亮相阶段允许更强，正文进入后由现有后处理继续压低存在感。
- WebGPU、WebGL2 和 static 共用同一 CSS 材质层，不修改生物模拟。

### Hero 视觉舞台

- 空闲状态以 `12.8 s` 连续周期做小幅俯仰和横摆。
- 光带在视觉视口内移动，不跨过 Hero 正文。
- 鼠标进入后由指针接管视差，离开后通过弹簧平滑回到空闲轨道。
- 真实照片接入后仍沿用同一材质层，不需要更改内容结构。

### 项目卡

- 空闲状态以 `11.2 s` 连续周期产生低于悬浮态的轻微倾斜。
- 只有当前活动卡拥有结构光；预览卡和切牌中的过渡卡保持安静。
- 鼠标悬浮时卡面倾角与材质光强同步提高，移出后恢复空闲运动。
- 光层位于卡片内容下方，不影响链接、详情面板、翻面和拖动。

## 性能与可访问性

- 连续数值由 Motion values 更新，不通过 React state 逐帧重渲染。
- 空闲轨道是可测试的周期函数，循环首尾位置连续。
- CSS 光带只动画 `transform` 和 `opacity`。
- 项目卡离开视口后停止材质扫光；移动端降低光层强度。
- `prefers-reduced-motion` 停止扫光和空闲视差，保留静态低对比材质提示。
- `prefers-reduced-transparency` 关闭混合模式并降低光层透明度。

## 范围

- 不改变信息架构、正文、真实链接和项目数据。
- 不修改 WebGPU 固定逻辑步进、海豚、水母和静物行为。
- 不修改 `D:\project\blog`。
