# v0.6 太空海洋生物独立动画 Demo

状态：第一版 Demo 已否决；第二版独立 Demo 已实现并等待用户审核，尚未集成主页。

## 范围与入口

- 独立路由：`/labs/space-ocean-demo/`
- 默认后端：WebGPU
- 强制降级：`?backend=webgl2`
- 静态兜底：`?backend=static`
- 强制完整动画：`?motion=full`
- 可视诊断日志：`?debug=1`，可与后端和动画参数组合
- 本阶段没有修改 `AmbientWorld.tsx`，也没有把生物合入主页。

## 第一版结论

第一版使用 Twemoji SVG 网格和随机目标游走。虽然 WebGPU、WebGL2 与移动端工程路径均可运行，但用户审核发现三个不可接受的问题：

- 海豚轮廓和局部尾部变形仍像蜷缩的玩具，缺乏成熟海豚的身体传导。
- 水平速度触发 `scaleX` 镜像，出现直接翻面式掉头。
- 随机目标切换让转弯半径和航向变化缺乏连续性，产生“航母掉头”或瞬间改向的观感。

因此第一版只保留为工程验证记录，不允许集成主页。下面记录第二版的实现合同。

## 第二版视觉组成

- 主生物改为程序化成熟侧视海豚，不再运行时加载 Twemoji。
- 海豚始终展示同一侧，整体可以在屏幕平面连续旋转 360 度，不做水平镜像。
- 身体由 8 个固定长度脊柱关节驱动，前半身稳定，尾段逐级放宽曲率。
- 可变形网格由脊柱切线、法线和预设宽度采样更新，身体、腹部、鳍和尾叶共享同一运动骨架。
- 桌面显示 3 只无表情月水母，移动端显示 2 只；钟罩呼吸，4 条触手使用短链滞后。
- 桌面使用 124 个方形像素浮游物，平衡档使用 72 个；另有 3 至 4 条 Catmull-Rom 流线。
- 深色使用深海墨色，浅色改为 `#f8faf8` 中性暖白，蓝色只保留在生物、流线和像素上。

## 第二版程序化行为

- 海豚默认沿平滑 8 字路径游动，路径相位按近似恒定弧长推进，不在外侧弯点减速后原地转身。
- 路径只直接驱动头部位置；第一节身体保留上一帧世界位置并被头部拖动，后续关节逐节追随，不再把整条脊柱强制对齐路径切线。
- 完整转圈、竖直和倒游都由同一条连续骨架形成，并始终保持同一侧可见。
- 指针斥力通过带阻尼的路径偏移参与转向，不直接覆盖海豚朝向。
- 鼠标只产生斥力，不吸引生物；移动越快，斥力越明显。
- 点击产生一次短促扩散脉冲，推开附近像素浮游物。
- 水母跟随缓慢流场；触手使用水母局部坐标的短链，回绕时整体重置，避免跨屏长线。
- 像素具有独立速度、闪烁、尾流和循环边界行为。
- 暂停、重置、深浅主题均提供图标控制和可访问名称。

## 第二版验收门槛

- 连续帧中相邻脊柱链节长度保持稳定，头部和胸腔不塌缩。
- 相邻关节角度不超过各段限制，尾部波动不会卷回身体。
- 航向跨越 `-π / π` 时仍连续，不出现接近 180 度的单帧跳变。
- 源码中不存在由速度符号驱动的镜像状态。
- 桌面、移动端、WebGPU、WebGL2、静态降级和 reduced motion 均可独立验收。

## 第一版 WebGPU 兼容决策

最初方案把 SVG 当作 `TextureLoader` 纹理贴到细分平面。实机 WebGPU 报错：

`copyExternalImageToTexture: Could not get the source image`

该错误会中断整帧，WebGL2 也无法稳定显示海豚。最终改为使用 `SVGLoader` 解析 Twemoji 路径，再生成 `ShapeGeometry` 网格。尾部动画直接修改主轮廓的局部顶点，因此不再依赖 SVG 外部图像纹理，WebGPU 与 WebGL2 输出一致。

## 性能与降级

- 移动端、低并发设备与 WebGL2 自动使用平衡档：较低 DPR、较少像素、较少曲线采样和较低几何细分。
- WebGPU 初始化超过 5 秒或直接失败时自动尝试 WebGL2；WebGL2 也失败时才进入静态兜底，页面不会永久停在 loading。
- `?debug=1` 在页面内显示初始化阶段、降级原因、首帧与帧心跳，同时向控制台输出同一组结构化日志。
- 页面隐藏时停止动画帧；恢复可见后重置时间步，避免大步长跳变。
- `prefers-reduced-motion: reduce` 时初始暂停并显示播放控制；用户主动播放或使用 `?motion=full` 后推进模拟。
- 透明度偏好关闭时，控制条退回纯色表面。
- 初始化失败时保留与第二版轮廓一致的静态侧视海豚。

浏览器验收曾发现统一 Three.js WebGPU 渲染器不支持 `THREE.LineLoop`。身体轮廓随后改为首尾点显式重复的普通 `THREE.Line`，重新建立干净 WebGPU 与 WebGL2 会话后均无 warning/error。

纯函数测试覆盖：

- 8 个脊柱点对应的 7 段链长在 240 帧内保持误差范围。
- 连续 480 帧环游中，每个关节均不超过分段曲率限制。
- 环游航向跨越 `-π / π` 时使用最短角差，没有单帧镜像式跳变。
- 8 字路径按近似恒定弧长推进，头部在外侧弯点和交叉点都持续前进。
- 头部发生转向位移时，第一节身体保留空间惯性后被拖动，不会立刻绕头对齐新航向。
- 指针斥力仍始终背离鼠标位置。

最终命令结果：

- `bun test`：14 passed、0 failed。
- `bun run check`：0 errors、0 warnings、0 hints。
- `bun run build`：2 个静态路由生产构建成功。

## 许可与门禁

第一版 Twemoji 资产与署名继续保留在历史概念文件中。第二版运行时不加载 Twemoji，因此 Demo 页不再展示 Twemoji 署名；链式约束思路参考 MIT License 的 `argonautcode/animal-proc-anim`，实现为本项目独立 TypeScript 代码，并在开发文档中注明来源。

下一步必须先由用户审核本 Demo。只有审核通过后，才允许新建集成分支并替换主页现有生物；本分支不合入 `develop` 或 `main`。
